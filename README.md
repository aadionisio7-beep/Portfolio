# Allen Clint Dionisio Portfolio

GitHub Pages-ready static portfolio.

## Files
- `index.html` - portfolio website
- `Resume_Allen_Clint_Dionisio.pdf` - downloadable CV
- `.nojekyll` - ensures static assets are served directly

## GitHub Pages
1. Upload all files to a public GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`.
5. Save.

Your site URL will be:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
